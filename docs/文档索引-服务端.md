# 服务端文档索引

线上机器、域名、目录和对象存储在 `ops.local.md`（不入库）。分析部署或容量时先读它。

## 开发

- [后端操作手册-OPS_PLAYBOOK.md](./后端操作手册-OPS_PLAYBOOK.md)：改了配置表、代码、环境变量或数据库之后，要跑哪条命令
- [快速开始-QUICK_START.md](./快速开始-QUICK_START.md)：本地启动和一次联调
- [环境配置-ENV_SETUP.md](./环境配置-ENV_SETUP.md)：环境变量
- [认证指南-AUTH_GUIDE.md](./认证指南-AUTH_GUIDE.md)：登录和 Token
- [接口参考-API_REFERENCE.md](./接口参考-API_REFERENCE.md)：当前接口
- [PostgreSQL配置-POSTGRES_CONFIG.md](./PostgreSQL配置-POSTGRES_CONFIG.md)：数据库怎么连
- [迁移手册-POSTGRES_MIGRATION.md](./迁移手册-POSTGRES_MIGRATION.md)：CloudBase 迁到 PostgreSQL 的分步操作
- [日志使用指南-LOGGER_USAGE.md](./日志使用指南-LOGGER_USAGE.md)：日志写到哪里、怎么打
- [版本验证-VERSION_VERIFICATION.md](./版本验证-VERSION_VERIFICATION.md)：用 `/api/version` 核对运行中的代码

## 阅读顺序

1. `快速开始-QUICK_START.md`
2. `环境配置-ENV_SETUP.md`
3. `认证指南-AUTH_GUIDE.md`
4. `接口参考-API_REFERENCE.md`
5. 若在做数据库迁移：`迁移手册-POSTGRES_MIGRATION.md`
6. 改完要发布时：`后端操作手册-OPS_PLAYBOOK.md`
